# 颐听 App · 最终开发流程与 T01/T02 验收方案

> 本文是当前开发基准。执行顺序固定为 T01 → T02 → T03……；T01 和 T02 都在当前 `dev_2.0` 分支完成，未完成验收前不开始 T03。

## 1. 产品目标

颐听是面向长辈的大字版 Android 听戏、听书、看书应用，核心是本地优先、打开即用、路径简单。不强制登录，不加入广告、推荐算法或社区。广播需要联网；本地文件与阅读功能不应依赖网络。

- 应用显示名：颐听。
- Android applicationId/namespace：`com.yiting.app`，不可更改。
- Kotlin、Jetpack Compose、Material 3，最低 Android API 26。
- 保留八模块：`app`、`core-ui`、`core-data`、`core-player`、`feature-radio`、`feature-book`、`feature-opera`、`feature-read`。`app` 负责组合与导航，feature 模块不互相循环依赖。

## 2. 页面与视觉规则

底部导航固定为三个大 Tab：

1. **首页**：最近在听、最近阅读、清楚的“看书”和“听广播”入口；广��尚未实现时明确提示“后续版本开放”，不做假播放按钮。
2. **听戏**：本地音频列表和扫描状态。T02 可以扫描、展示媒体信息，但不播放；播放属于 T03。
3. **听书**：明确显示功能状态；有声书播放属于后续任务，不在 T01/T02 假装已实现。

视觉与无障碍基准：品牌强调色 `#FA2D48`；白底深色文字优先，所有文字对比清晰。正文以 20sp 为目标、标题 28sp 起；一般触控区域至少 48dp，主要动作至少 96dp，列表项至少 72dp。系统字体缩放和大字号下不能裁切。TalkBack 标签及焦点顺序清楚。

## 3. 分支和任务版本号

- 当前开发分支：`dev_2.0`，在这里完成 T01（任务版本 1.0）和 T02（任务版本 2.0）。任务版本号与开发分支名不是一回事。
- 当前稳定分支：`release_2.0`。T01/T02 分别验收后，以 PR 从 `dev_2.0` 合入 `release_2.0`。
- `main` 只从验收后的 release 分支合入，不直接开发。
- T02 完成并验收后，从稳定基线创建 `dev_3.0`，再做 T03（任务版本 3.0）；以后按任务顺序递增。
- `dev_1.0`、`release_1.0` 保留为历史分支，不将本轮修复回移到旧分支。
- App 的 `versionName`/发布标签按当前任务版本管理：T01 `1.0`，T02 `2.0`，T03 `3.0`……；每次发布递增 `versionCode`。不要将开发分支名误当成 App 版本。

## 4. 每项任务的工作循环

1. 明确本任务范围、文件清单、验收标准和权限/数据影响。
2. 代码提交到规定的 `dev_x.0`，提交信息使用 `[T0X] 描述`。
3. GitHub Actions 至少构建 Debug APK；计划中的单元测试、Lint 也要运行。构建成功仅代表编译通过，不代表功能验收通过。
4. APK 安装到模拟器或设备，按任务验收清单逐项验证；记录设备/Android 版本、步骤和结果。
5. 失败时先修复再重跑 CI 与相应验证。
6. 任务验收通过后再 PR 合入对应 `release_x.0`。稳定发布再 PR 合入 `main`。
7. Release 签名密钥不可提交到仓库；用受保护的 Secrets 或安全的离线方式保管并备份。

## 5. T01 · 项目骨架与基础体验（任务版本 1.0）

### 范围

- 八模块均可被 Gradle 配置并成功构建，依赖方向清楚。
- 固定并核对 Gradle、AGP、Kotlin、Compose、KSP 兼容版本；版本目录作为依赖版本来源。
- CI 使用固定 Gradle 版本构建；优先使用 Gradle Wrapper（包含 wrapper 脚本、properties 和 wrapper JAR）。如当前仅能网页编辑，不能生成 wrapper JAR，则先保留 CI 中明确固定的 Gradle 版本，并将 Wrapper JAR 的补入作为 T01 未完成项，不能误称已使用 Wrapper。
- 实现应用名和包名、统一主题（只以 `core-ui` 为主题单一来源）、首页/听戏/听书三 Tab 的基础导航与占位状态。
- 双击返回提示后退出；页面内层（如 TXT 阅读器）先返回页面，不能误触双击逻辑直接退 App。

### 验收

- 干净检出后 CI 可构建并上传 APK，测试和 Lint 任务可运行。
- 安装后应用名为“颐听”，包名为 `com.yiting.app`。
- 三 Tab 正确切换；主色、字号、触控尺寸符合本文件基准。
- 在首页连续两次按返回退出；首次只提示，不退出。

## 6. T02 · 首页、Room、本地内容发现与 TXT 续读（任务版本 2.0）

### 范围

- 首页：大标题、最近在听空状态/数据列表、最近阅读、看书入口、广播入口/未开放提示。
- Room 数据结构：媒体条目、播放记录、收藏、阅读进度；包括 DAO、Repository、ViewModel 接线和明确的数据库迁移。最近在听当前没有真实播放来源时，验收空状态与可观察列表即可，不提前实现播放。
- TXT：通过系统文件选择器导入；保留可持久化的 URI 读取授权；限制合理文件大小并显示加载、空内容、读取失败状态；保存实际滚动位置并能从首���“最近阅读”重新打开并恢复。文件不可访问时显示可操作错误提示。
- 听戏页通过 MediaStore 查询本地音频，按 Android 版本申请所需的最小权限；显示加载、无内容、拒绝权限、扫描失败和重试状态。T02 只扫描/展示，不播放、不加入 Media3 服务；播放留给 T03。
- 大字、大触控、列表行高、空状态和错误状态在小屏与系统字体放大时布局可用。
- 广播入口当前只明确说明尚未开放；实际电台目录和播放留到 T04，不在 T02 填入未经验证的流地址。

### 验收

- 首次启动、拒绝媒体权限、无本地音频、有本地音频、扫描失败/重试均有清晰页面，不白屏。
- TXT 可选取、阅读、滚动、返回后从“最近阅读”重开并恢复位置；关闭再启动后仍可继续；失效 URI 有明确提示。
- Room 的播放记录/收藏/媒体条目/阅读进度表可创建与读取；旧数据库升级不会丢数据或崩溃。
- 首页入口易发现；三 Tab 导航及双击返回行为符合 T01；页面没有声称尚未实现的播放能力。

## 7. 后续任务（T01/T02 验收后再开始）

### T03 · 播放内核（任务版本 3.0）

Media3 播放服务/MediaSession；本地文件播放、播放控制、进度、倍速、定时停止、状态恢复、音频焦点、息屏、耳机与蓝牙线控。验收真实音频播放和恢复行为。不能承诺进程被系统杀死后仍持续播放。

### T04 · 听戏分类与广播（任务版本 4.0）

分类建议可手动修正、收藏/置顶；电台使用合法且经验证的来源，提供失败/重试/切换状态。电台数量以实际确认可用为准，不预先保证固定数量。

### T05 · 听书与阅读增强（任务版本 5.0）

有声书章节、续播与倍速；TXT 字号、行距、翻页按钮、夜间模式和可选 TTS。检查中文 TTS 引擎，缺失时给出说明。

### T06 · 设置和无障碍（任务版本 6.0）

全局字号三档、定时默认时长、清理缓存、关于；TalkBack 核心流程、统一加载/空/错误/重试组件。

### T07 · 发布准备（任务版本 7.0）

回归 T01–T06，清理调试代码，完善 README、安装说明、支持格式、权限说明、截图和已知问题；验证签名、版本升级和新装。正式版目标版本号按产品发布决策确定，不能与任务版本号混为一谈。
